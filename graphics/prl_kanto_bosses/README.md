# Approved Kanto trainer cosmetics

Front LZ10 files contain two64x64frames and each RGB555 palette is16colors. Static imported graphics duplicate their frame; PKR imports retain both donor frames. PNGs are previews. Explicit Makefile rules preserve imported binaries. Manifests pin source and binary hashes; no global species replacement or Mega mechanics.

Blaine uses PJR ARCANINE_MEGA_REDUX (top-right); Champion uses ARCANINE_MEGA (bottom-left). SS2 WEEZING_2 is blue/white (earlier Silph Jessie/James); WEEZING is red/fire (final Kanto encounter). Donor backs and available fiery shiny front/back are archived for future development. Blue/white shiny files were unavailable, so no fabricated shiny variant. Existing Kanto parties are unchanged by the Weezing graphics.

Future Hoenn/Johto: rotate recognisable Jessie/James variants of Arbok, Victreebel, Wobbuffet, Seviper, Cacnea/Cacturne, Chimecho and Meowth through existing approved teams, using SS2 source front/back/shiny palettes after visual review. Do not add encounters or members merely to accommodate cosmetics. Both approved Kanto Weezings remain in Kanto. No future-region progression implemented here.
