# Real Pokemon Infinity donor sprite review

Only original Pokemon Infinity artwork is used, from the Pokengine Infinity Collection.
Everything is in sprite-review/ and is NOT imported into the ROM.

Original sources and SHA256 are in VALIDATION.json. Normal fronts/backs are indexed 64x64 PNGs; icons are indexed 32x64 PNGs, each with 16-slot JASC/PoryPal palette files. Two icon frames reuse the original source icon without inventing art.

SHINY IS NOT COMPLETE. The original shiny donor files have not been verified; no fake recolours have been inserted.
Approved PRL evolution: Eeveeon = Relic Stone, unchanged by this asset-only task.
